# Доля попаданий: первые измерения

Каждая ячейка показывает процент попаданий на 10 000 запросов. Больше — лучше.
Все конфигурации одноуровневые, каждый прогон начинается с пустого кеша.

Источник: [baseline.csv](baseline.csv). Условия: [README.md](README.md).
Для случайной нагрузки использован один seed: 42. Время работы здесь не измерялось.
